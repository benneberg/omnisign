# Future Roadmap
## Phase 14+: Advanced Features
### 🛠️ Hardware Integration
- [ ] **Electron Wrapper:** Native shell for Windows/Linux players.
- [ ] **Cordova/Capacitor Build:** Target APK for Android-based signage players.
- [ ] **Hardware Watchdog:** Integration with physical system timers for hard reboots.
### 🔐 Security Enhancements
- [ ] **SAML/OIDC:** Integration for enterprise SSO on the CMS dashboard.
- [ ] **Multi-Tenant Isolation:** Use OrgId-based DO namespaces for strict data separation.
- [ ] **Hardware Root of Trust:** TPM-backed key storage for supported hardware.
### 📊 Analytics & Telemetry
- [ ] **Proof-of-Play (PoP):** Cryptographically signed logs for ad-verification.
- [ ] **WebSocket Telemetry:** Real-time push for "Live View" monitoring in the CMS.
- [ ] **AI-Powered Watchdog:** Predicting hardware failure based on CPU/Mem temperature trends.
### 📦 Content Distribution
- [ ] **P2P Mesh Mesh:** Local network content sharing between nodes to save bandwidth.
- [ ] **Pre-caching Heuristics:** Background downloading of the *next* playlist revision before it is activated.
- [ ] **Dynamic Widgets:** LUA or JavaScript sandboxed widgets for real-time data overlays.
